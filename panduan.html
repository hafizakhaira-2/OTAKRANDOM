Generator Panduan

📖 Panduan Pakai OTAKRANDOM

Website ini adalah generator pemikiran random / overthinking. Data-nya hidup di Google Sheets lewat Apps Script — gratis, tanpa server sendiri.

Untuk Pengunjung

🎲 Generate pemikiran

Pilih kategori (Random, Absurd, Deep, atau Jam 2 Pagi), lalu klik tombol “Aku kepikiran sesuatu...” atau LAGI. Setiap klik menghitung counter lokal di browser kamu + total global di database.

✍️ Kirim pemikiran sendiri

Klik “Kirim pemikiran random kamu”, isi kategori + teks (min 10 karakter), lalu submit. Submission masuk status Pending dan baru muncul di generator setelah admin approve.

Fitur Database (yang jalan di belakang layar)

  • Thoughts — daftar pemikiran yang sudah disetujui. Hanya yang status Approved yang muncul di generator.
  • Submissions — antrian kiriman dari pengunjung (Pending → Approved / Rejected).
  • Stats — counter global total_generates yang naik setiap ada yang generate.

Semua data disimpan di Google Spreadsheet. Frontend (GitHub Pages) hanya memanggil API Apps Script. Tidak ada password atau ID spreadsheet yang disimpan di kode frontend.

Untuk Admin

🔐 Masuk panel admin

Klik tombol Admin di header → masukkan password Bismillaah. Session disimpan di sessionStorage (hilang kalau tab ditutup).

📝 Kelola Thoughts (CRUD)

  • Lihat semua thought (termasuk Draft / Hidden)
  • Filter by teks atau status
  • Edit kategori, emoji, teks, status
  • Hapus thought
  • Tambah thought baru lewat tab “➕ Tambah”

📥 Review Submissions

  • ✅ Approve — otomatis copy ke sheet Thoughts (status Approved) + tandai submission Approved
  • ❌ Reject — ubah status jadi Rejected
  • 🗑️ Hapus — buang dari sheet

Setup teknis (sekali saja)

  1. Buat Google Spreadsheet dengan 3 sheet: Thoughts, Submissions, Stats + header yang benar.
  2. Paste Code.gs ke Apps Script.
  3. Set Script Properties:
    • SPREADSHEET_ID = ID spreadsheet
    • ADMIN_PASSWORD = Bismillaah
  4. Deploy sebagai Web app (Anyone, Execute as Me) → copy URL /exec.
  5. Paste URL itu ke script.js → const API_URL = "...".
  6. Jalankan fungsi seedInitialData() sekali dari editor Apps Script untuk isi data awal.
  7. Upload frontend ke GitHub Pages.

Kenapa Script Properties?

Karena website di-host di GitHub Pages (public). Kalau password / spreadsheet ID ditulis di file JS, siapa saja bisa lihat. Script Properties hanya bisa dibaca oleh Apps Script yang jalan di sisi Google — aman.
